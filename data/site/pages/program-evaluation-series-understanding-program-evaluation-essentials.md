# Program Evaluation Series: Understanding Program Evaluation Essentials

InnovateUS workshop · 5 October 2023 · 90 minutes

Program evaluation is a systematic process of assessing the design, implementation, and impact of a project or initiative to determine its effectiveness, efficiency, equity, and overall value. In this 90-minute virtual training, participants will gain a comprehensive understanding of how program evaluation empowers professionals in state and local governments to make informed choices, enhance program effectiveness, ensure optimal resource allocation, and take into consideration equity opportunities and challenges. Participants will learn the fundamentals of each of the six steps in program evaluation; understand the differences between inputs, outputs, and outcomes; identify sources of data and data collection; the importance of stakeholder engagement; how to communicate program evaluation results; and ethical considerations in program evaluation. Real-world examples will be used to illustrate the key points in the workshop.

## Learning goals

- Gain a comprehensive understanding of how program evaluation empowers professionals in state and local governments to make informed choices, enhance program effectiveness, ensure optimal resource allocation, and take into consideration equity opportunities and challenges. 
- Learn the fundamentals of each of the six steps in program evaluation
- Learn from real-world examples that illustrate key points of program evaluation
