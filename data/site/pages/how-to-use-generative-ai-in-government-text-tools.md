# How to Use Generative AI in Government: Text Tools

InnovateUS workshop · 7 December 2023 · 60 minutes

Join us for this 60-minute virtual training with Beth Noveck, New Jersey's Chief Innovation Officer and Director of the GovLab. In this hands-on tutorial, participants will learn about generative artificial intelligence tools like ChatGPT, Bard and Claude and how to use them in their everyday work. This workshop will focus on tools to help with generating, summarizing, translating and analyzing text and how to use them to improve government services.

## Learning goals

- Learn how to apply generative AI tools like ChatGPT, Bard, and Claude in everyday work.
- Learn about tools that help with generating, summarizing, translating, and analyzing text
- Understand how to use these tools to improve government services.
