# Human-Centered Design Series: Putting the 5 Key Phases into Action

InnovateUS workshop · 6 December 2023 · 90 minutes

In this 90-minute virtual training, participants will learn about implementing the 5 key phases of the human-centered design process: empathize, define, ideate, prototype, and test. Participants will learn about how each of these stages is addressed and accomplished in the human-centered design process, and will walk away with specific tools and strategies for each of the 5 phases.

## Learning goals

- Learn about the 5 key phases of the human-centered design process: empathize, define, ideate, prototype, and test
- Learn how each of these stages is addressed and accomplished
- Learn about specific tools and strategies for each of the 5 phases.
