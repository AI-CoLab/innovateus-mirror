# Module 2: Explaining GenAI and machine learning

## Explaining GenAI and machine learning

In this module, participants will learn the basics and capabilities of GenAI and machine learning and how these technologies differ. The module explains what large language models (LLMs) are and how they process data and what’s happening under the hood when you type something in. It also introduces how public sector lawyers can use GenAI to conduct their work more efficiently and effectively while safeguarding privacy.
