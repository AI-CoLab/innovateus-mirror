::knowledge-check{kind="one"}
What is meant by keeping "AI on tap, not on top"?

- [x] Storing AI tools in secure locations

  This phrase refers to the decision-making relationship, not physical security.
- [ ] Using AI to support, not replace, human judgment
- [ ] Prioritizing paid AI services over free versions

  The principle applies regardless of whether services are free or paid
- [x] Keeping AI systems updated with the latest software

  Software updates are important but unrelated to this principle
::

::knowledge-check{kind="one"}
According to the American Bar Association, what ethical obligation do lawyers have regarding AI use?

- [x] To avoid using AI tools for any client-related work

  The ABA does not prohibit AI use but provides guidance on responsible implementation
- [ ] To disclose AI use to clients, especially when it might conflict with expectations
- [ ] To use only AI tools specifically designed for legal applications

  The ABA doesn't limit lawyers to legal-specific AI tools
- [x] To become proficient in AI programming before using such tools

  Programming proficiency is not required for responsible AI use
