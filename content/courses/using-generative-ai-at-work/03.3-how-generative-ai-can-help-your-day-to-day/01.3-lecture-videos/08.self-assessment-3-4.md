::knowledge-check{kind="one"}
When using generative AI for a large project, what is the recommended approach?

- [x] Use AI to complete the entire project at once

  Attempting to use AI to complete an entire large project at once is not the most effective approach.
- [ ] Break the project down into smaller, specific tasks
- [ ] Avoid using AI for large projects altogether

  AI can be useful for large projects when the work is broken down into smaller tasks.
- [x] Expect AI to replace all human involvement in the project

  AI is a tool to assist with tasks, not a complete replacement for human involvement in a project.
