::knowledge-check{kind="one"}
Which of the following best describes the "Golden Rule of AI Data Security"?

- [x] Always encrypt all data before using any AI tool

  Encryption alone doesn't address privacy concerns with third-party tools
- [ ] Create a separate email account for AI interactions

  Separate email accounts don't provide adequate security for sensitive data
- [ ] Do not use public, free AI tools for sensitive information
- [x] Only use AI tools created within the last six months

  Recency of tool creation doesn't determine security level
::

::knowledge-check{kind="one"}
What distinguishes sensitive from non-sensitive information in the context of AI use?

- [x] Sensitive information is always in written form

  Format doesn't determine sensitivity; content does
- [ ] Sensitive information could compromise privacy, safety, or legal integrity if exposed
- [ ] Sensitive information always contains personally identifiable information (PII) about clients

  While PII is often sensitive,  PII about clients is just one type of sensitive information
- [x] Sensitive information uses technical terminology

  Technical terminology doesn't make information sensitive
::
