::knowledge-check{kind="one"}
What is the defining characteristic of supervised learning?

- [x] A. The AI model learns from data that is put into specific categories, also called "labeled data"
- [ ] B. The AI model learns from data without any predefined categories or labels
- [ ] C. The AI model is explicitly programmed with rules and logic
- [ ] D. The AI model learns through trial and error and receives feedback in the form of rewards or penalties

:::feedback{when="incorrect"}
The correct answer is A. Supervised learning is defined by the AI model learning from data that is labeled with specific categories. This differs from unsupervised learning (B), traditional programming (C), and reinforcement learning (D).
:::
::

::knowledge-check{kind="one"}
What is the key difference between unsupervised learning and supervised learning?

- [x] A. Unsupervised learning models are more accurate than supervised learning models
- [ ] B. Unsupervised learning models are trained on unlabeled data, while supervised learning models are trained on labeled data
- [ ] C. Unsupervised learning is used for classification tasks, while supervised learning is used for anomaly detection
- [ ] D. Unsupervised learning requires more human expertise than supervised learning

:::feedback{when="incorrect"}
The correct answer is B. The key difference between unsupervised and supervised learning is that unsupervised learning models are trained on unlabeled data, while supervised learning models are trained on labeled data. The relative accuracy (A), typical use cases (C), and required human expertise (D) mentioned in the other options are not the defining distinctions between the two approaches.
:::
::
