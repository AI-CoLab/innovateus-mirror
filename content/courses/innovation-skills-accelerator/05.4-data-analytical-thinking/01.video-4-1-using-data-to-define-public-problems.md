In this video, we look at the use of data as an essential and complementary set of methods to understand a problem better. It can feel like data is everywhere. And the public sector has increasingly put a premium on using data and evidence to improve policies and programs. The costs of gathering data is far outweighed by the opportunity costs of not using it, which is why in this module we will discuss the use of data and evidence to define problems.
