# Video 4.4: Risks while using data

We’ve Introduced the steps involved in using data to define and assess a problem. But because data use is still new to many departments, it is critical to address a few commonly held misperceptions. With the ubiquity of data, more and more government departments are receiving mandates to perform sophisticated analysis. However, there can be pressure to move quickly when using data. Don’t let such pressure be an impediment to undertaking data analysis. Go at your own pace. What’s key is to start somewhere.
