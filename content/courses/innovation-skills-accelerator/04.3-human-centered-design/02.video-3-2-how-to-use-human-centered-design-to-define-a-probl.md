# Video 3.2: How to use Human Centered Design to Define a Problem

In this video, we will get to work using human centered design to define a problem. The qualitative research we’ll do has roots in anthropology, ethnography, and other disciplines. We will walk you through some of these approaches. There are dozens of techniques for structuring a conversation to elicit people’s lived experience, and using the input to define a problem. Here, we’ll discuss two related methods for engaging with people to define a problem: interviewing and service blueprinting.
