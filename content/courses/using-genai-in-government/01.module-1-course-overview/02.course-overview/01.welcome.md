# Welcome!

## Module 1: Course Overview

This module introduces the course and highlights the transformative potential of Generative AI (GenAI) in the public sector. Participants will gain an understanding of how GenAI can assist them in their work through hands-on activities and best practices. The importance of delivering value while maintaining public trust and safety is emphasized.

After each video ends, a continue button appears below the video player. Click it to reveal the additional navigation and the InnovateUS website link containing readings and resources. Learners with screen readers can use the down arrow key to navigate through the video player’s controls and access the continue button. Another “continue” button will appear to move on to the Self-Assessments after each video.

**Audio description transcripts**\
All videos in this module include audio description transcripts. You’ll find them directly below each video in an accordion titled “Audio description transcript”

- Select the heading to expand and read the transcript.

- **Screen reader and keyboard users:** tab to the accordion heading and press Enter or Space to open or close it.
